# هدر المنتور – بازرگانی پردیس

دو فایل JSON برای ایمپورت در المنتور:

| فایل | کاربرد |
|---|---|
| `pardis-header-pro.json` | قالب **Header** برای Theme Builder المنتور پرو (لوگو خودکار از تنظیمات سایت خوانده می‌شود) |
| `pardis-header-section.json` | همان هدر به‌صورت **Section** (اگر می‌خواهید داخل یک صفحه یا قالب دیگر درج کنید) |

## نصب
1. پیشخوان وردپرس ← **قالب‌ها ← Theme Builder** (یا **قالب‌های ذخیره‌شده**) ← **وارد کردن قالب‌ها** ← انتخاب فایل JSON.
2. قالب را باز کنید و در ویجت **منوی اصلی** منوی سایت را انتخاب کنید.
3. **انتشار** ← شرط نمایش: «کل سایت».

> پیش‌نیاز: المنتور پرو (ویجت‌های Nav Menu، Animated Headline، Search Form و Sticky)، و فعال بودن **Flexbox Container**.

## چیزهایی که باید ویرایش کنید
- شماره تلفن `۰۲۱-۰۰۰۰۰۰۰۰` (نوار بالا، باکس «مشاوره رایگان»، آیکن تماس موبایل)
- ایمیل، لینک‌های اینستاگرام / واتساپ / تلگرام / لینکدین
- لینک دکمه «ثبت درخواست واردات» (پیش‌فرض: `/contact/`)
- در نسخه Section: تصویر لوگو

## ساختار و افکت‌ها
- **نوار بالا** (گرادیان سرمه‌ای): اطلاعات تماس + تیتر چرخان خدمات + آیکن‌های اجتماعی
- **هدر اصلی** (سفید): لوگو و شعار ← منو با خط زیرین متحرک قرمز ← جستجوی تمام‌صفحه، مشاوره تلفنی، دکمه CTA
- هدر **چسبان** است؛ بعد از ۹۰px اسکرول، نوار بالا جمع می‌شود، هدر شیشه‌ای (blur) می‌شود و لوگو کوچک می‌شود
- خط گرادیان متحرک زیر هدر، درخشش و پالس روی دکمه CTA، زنگ خوردن آیکن هدست
- موبایل: لوگو + همبرگر منو + آیکن تماس

همه رنگ‌ها و انیمیشن‌ها در ویجت HTML با عنوان «استایل و انیمیشن‌ها (CSS)» قابل تغییرند (متغیرهای `--pi-red` و `--pi-slate`).
