# هدر المنتور – بازرگانی پردیس

| فایل | کاربرد |
|---|---|
| `pardis-header-pro.json` | قالب **Header** برای Theme Builder المنتور پرو (لوگو خودکار از تنظیمات سایت) |
| `pardis-header-section.json` | همان هدر به‌صورت **Section** (برای درج داخل صفحه؛ تصویر لوگو را دستی انتخاب کنید) |

## نصب
1. **قالب‌ها ← Theme Builder ← وارد کردن قالب‌ها** ← انتخاب فایل JSON.
2. در دو ویجت **منوی اصلی (دسکتاپ)** و **منوی موبایل (آکاردئونی)** منوی سایت را انتخاب کنید.
3. **انتشار** ← شرط نمایش: «کل سایت».

پیش‌نیاز: المنتور پرو + فعال بودن **Flexbox Container**.

## ساختار
- **نوار بالا**: تماس، تیتر چرخان خدمات، شبکه‌های اجتماعی (در موبایل مخفی)
- **هدر اصلی**: لوگو | منوی مینیمال در وسط | جستجوی زنده + دکمه درخواست
- **جستجوی زنده**: آیکن کوچک؛ با تایپ (از ۲ حرف) **فقط برگه‌ها** با عنوان و خلاصه محتوا نمایش داده می‌شوند (REST API وردپرس)؛ Enter ← صفحه کامل نتایج برگه‌ها. در موبایل پنل تمام‌عرض زیر هدر باز می‌شود.
- **مگامنو خدمات** (دسکتاپ): با هاور روی «خدمات ما» باز می‌شود؛ ۶ خدمت + کارت زرشکی مشاوره. **لینک خدمات خودکار از زیرمنوی وردپرس خوانده می‌شود** (عنوان خدمت در مگامنو باید با عنوان زیرمنو یکی باشد).
- **منوی موبایل کشویی**: از راست باز می‌شود؛ لوگو، دکمه بستن، منوی آکاردئونی، دکمه‌های تماس و واتساپ، شبکه‌های اجتماعی

در ویرایشگر المنتور، مگامنو و منوی موبایل **باز نمایش داده می‌شوند** تا بتوانید متن، آیکن و لینک‌ها را مستقیم ویرایش کنید. در سایت، مخفی‌اند و با هاور / دکمه همبرگری باز می‌شوند.

## تنظیمات در ویجت «استایل و اسکریپت هدر (CSS/JS)»
- `MEGA_ITEM = 'خدمات ما'` ← متن آیتمی از منو که مگامنو را باز می‌کند (یا کلاس CSS `pi-mega-trigger` را به آن آیتم در «نمایش ← فهرست‌ها» بدهید)
- `SEARCH_LIMIT` ← تعداد نتایج جستجو؛ `SEARCH_TYPE` ← `'pages'` (فقط برگه‌ها) یا `'posts'` (نوشته‌ها)
- `BADGES = { 'مقالات': 'جدید' }` ← برچسب کنار آیتم‌ها
- رنگ‌ها: `--pi-red`، `--pi-slate`، `--pi-tint` در ابتدای CSS

## موارد قابل ویرایش
- تلفن `۰۲۱-۰۰۰۰۰۰۰۰` (نوار بالا، کارت مگامنو، آیکن تماس موبایل، دکمه «تماس» منوی موبایل)
- شماره واتساپ و لینک شبکه‌های اجتماعی
- لینک دکمه درخواست (`/contact/`)

## ریسپانسیو
| اندازه | نوار بالا | هدر اصلی |
|---|---|---|
| دسکتاپ (بالای ۱۳۰۰) | تماس + ایمیل + ساعت، تیتر چرخان، شبکه‌های اجتماعی | لوگو، منو در وسط، جستجو، دکمه درخواست |
| لپ‌تاپ (۱۰۲۵–۱۳۰۰) | ساعت کاری مخفی | فاصله منو و دکمه کوچک‌تر |
| تبلت (۷۶۸–۱۰۲۴) | تلفن + ایمیل + شبکه‌ها | لوگو، جستجو، دکمه درخواست، همبرگری |
| موبایل (تا ۷۶۷) | تلفن + شبکه‌ها (زیر ۳۶۰px فقط تلفن) | لوگو، جستجو، همبرگری؛ جستجو تمام‌عرض |

## به‌روزرسانی بدون ایمپورت مجدد
اگر نمی‌خواهید تغییرات قبلی خود در المنتور از دست برود:
1. محتوای `header-code-widget.html` را جایگزین محتوای ویجت «استایل و اسکریپت هدر (CSS/JS)» کنید.
2. محتوای `search-widget.html` را جایگزین ویجت «جستجوی زنده (دسکتاپ)» کنید و در تب پیشرفته ← واکنش‌گرا، «مخفی در موبایل» را خاموش کنید.
3. در کانتینر «نوار بالا (Top Bar)» گزینه «مخفی در موبایل» را خاموش کنید.
4. ویجت «تماس (موبایل)» را حذف کنید (تلفن در نوار بالا و منوی موبایل هست).
